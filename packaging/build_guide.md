# راهنمای پکیج کردن و انتشار اپلیکیشن در کافه‌بازار (Career Co-Pilot Pro)

این راهنما مراحل تبدیل این پلتفرم به فایل خروجی قابل نصب اندروید (`.apk` یا `.aab`) و ثبت در پنل توسعه‌دهندگان کافه‌بازار را شرح می‌دهد.

---

## ۱. مشخصات بسته نرم‌افزاری (Package Specification)

- **نام اپلیکیشن:** دستیار هوشمند شغلی (Career Co-Pilot)
- **شناسه بسته (Package Name):** `ir.careercopilot.app`
- **نسخه (Version):** `1.0.0` (کد نسخه: `1`)
- **حداقل نسخه اندروید:** Android 7.0 (API Level 24)
- **دسترسی‌های مورد نیاز (Android Permissions):**
  - `android.permission.INTERNET`: اتصال به شبکه کاربورد، جابینجا و سرور هوش مصنوعی
  - `android.permission.RECORD_AUDIO`: استفاده از میکروفون در اتاق شبیه‌ساز مصاحبه صوتی
  - `android.permission.READ_EXTERNAL_STORAGE`: انتخاب و آپلود فایل رزومه PDF/Word

---

## ۲. روش اول: ساخت سریع APK با Bubblewrap / TWA (روش استاندارد گوگل و بازار)

سریع‌ترین و پایدارترین روش برای تبدیل داشبورد ریسپانسیو به APK بدون باگ و با کمترین حجم (زیر ۵ مگابایت):

```bash
# 1. نصب ابزار استاندارد گوگل Bubblewrap CLI
npm install -g @bubblewrap/cli

# 2. مقداردهی اولیه برای آدرس سرور اپلیکیشن
bubblewrap init --manifest="http://your-domain.com/manifest.json"

# 3. بیلد خروجی APK برای کافه‌بازار
bubblewrap build
```

فایل نهایی در مسیر `app-release-signed.apk` ساخته شده و آماده آپلود در پیشخان کافه‌بازار است.

---

## ۳. روش دوم: پروژه نیتیو Flutter

اگر می‌خواهید از فریم‌ورک فلاتر نصب شده روی سیستم استفاده کنید:
1. یک پروژه فلاتر با نام `career_copilot_mobile` ایجاد می‌شود:
   ```bash
   flutter create --org ir.careercopilot career_copilot_mobile
   ```
2. با اضافه کردن پکیج `webview_flutter: ^4.10.0`، آدرس داشبورد یا API محلی لود می‌شود.
3. بیلد نهایی:
   ```bash
   flutter build apk --release
   ```
