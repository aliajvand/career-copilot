# web-scraping-ethical
جمع‌آوری قانون‌مدار و اخلاقی داده‌ها.
- رعایت قوانین robots.txt و فواصل زمانی بین درخواست‌ها
- عدم تحمیل بار اضافه به سرورهای مقصد
- گزارش شفاف و بدون پنهان‌کاری در صورت نیاز به نشست لاگین
