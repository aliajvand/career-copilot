# svg-icon-system
سیستم وکتورهای SVG اختصاصی.
- وکتورهای بهینه شده، درون‌خطی و بدون وابستگی سنگین
- نسخه‌های اختصاصی RTL برای آیکون‌های جهت‌نما
- انیمیشن‌های ملایم CSS برای واکنش به ماوس
