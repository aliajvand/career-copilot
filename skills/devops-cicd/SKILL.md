# devops-cicd
خط لوله یکپارچه‌سازی و استقرار پیوسته.
- پیکربندی گردش کار GitHub Actions برای اجرای تست‌ها
- بررسی لینت و صحت ساختار فایل‌ها قبل از ادغام
- مستندسازی فرآیند بازگشت به نسخه قبل (Rollback)
