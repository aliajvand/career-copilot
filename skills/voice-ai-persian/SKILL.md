# voice-ai-persian
پردازش صوت و مکالمه فارسی.
- استفاده از Web Speech API با قابلیت بازگشت به متن در صورت خطا
- نمایش نشانگر وضعیت صوتی در حال ضبط و پخش
- ارائه رونوشت دقیق متنی هم‌زمان با خوانش صوتی
